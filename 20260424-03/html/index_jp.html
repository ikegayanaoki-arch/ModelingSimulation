05-01 講義: 1次元および2次元の定常熱伝導方程式

日時: 2026-05-01 08:41:16

場所: [場所を挿入]

講師: [氏名を挿入]

概要

この講義では、まず先週扱った1次元の定常熱伝導方程式と、有限体積法（FVM）による離散化の流れを復習し、その後、理論解と数値解が一致する3つのケース、すなわち断熱、一定の熱損失、位置依存の熱損失を確認した。続いて主題である2次元の定常熱伝導方程式へ拡張し、2次元の支配方程式を定義し、ディリクレ条件やノイマン条件を含む3種類の境界条件を設定して、数値シミュレーションの準備を行った。最後に、2次元領域を離散化するための制御体積、グリッド、ノードの定義を説明した。この一連の流れは、より一般的なポアソン方程式の解法にもつながる重要な基礎である。

知識点

1. 1次元定常熱伝導方程式の復習

有限体積法（FVM）による離散化

先週学んだ1次元定常熱伝導方程式を、有限体積法（FVM）で離散化する手順を復習した。

対象領域をノードに分割し、各ノードは体積の中心に置かれ、その位置の温度を代表する。

支配方程式を制御体積に対して積分し、ガウスの定理を使って2階微分項を1階微分項に変換し、東側（E）と西側（W）の境界で評価する。

境界での温度勾配は、隣接ノード間の温度差を距離で割ることで近似する。

これらを積分方程式へ代入して整理することで、ノード i の温度 Ti を隣接ノード Ti+1、Ti-1 から計算する離散化方程式を導出する。

この式は反復法で解き、予測値（ランダムな初期値や前ステップの値）から始めて収束するまで繰り返す。

3つのシミュレーションケースと結果

1次元熱伝導について3つのケースを検討した。

ケース1: 完全断熱

理想的な条件で、温度分布は線形になる。理論演習には向くが現実的ではない。

ケース2: 一定の熱損失

位置によらず一定の熱損失を仮定する。温度は一様値にはならない。

ケース3: 位置依存の熱損失

表面温度に応じて熱損失が変化する。最も現実的であり、以前にNHKの映像で見た、ある位置からほぼ一定になる温度分布と質的に一致する。

どのケースでも理論解（破線）と数値解（赤線）は完全に一致し、手法の妥当性が確認された。

2. 2次元定常熱伝導方程式への拡張

2次元熱伝導の概要

1次元の考え方を、より現実的な2次元の正方形平板における熱伝導へ拡張する。

温度は位置の関数 T(x, y) として表され、定常状態なので時間 t は含まれない。

目的は、2次元定常熱伝導方程式をFVMで離散化し、数値シミュレーションを行うことである。

支配方程式

一般的な熱伝導の支配方程式は、熱の蓄積項、熱伝導項（ラプラシアン）、熱源・熱吸収項から構成される。

ρCp * ∂T/∂t = λ * (∂²T/∂x² + ∂²T/∂y²) + Q

α = λ / (ρCp) は熱拡散率である。

定常状態では ∂T/∂t = 0 なので、

∂²T/∂x² + ∂²T/∂y² = -Q / λ

この形はポアソン方程式として知られ、熱伝導だけでなく多くの物理現象に現れるため、その解法を学ぶことが重要である。Q = 0 の場合はラプラス方程式になる。

2次元シミュレーションの3つのケース

ケース1: 固定温度条件（ディリクレ条件）

上辺を高温 TH、他の3辺を低温 TL に固定する。熱は上辺から他の辺へ伝わると予想される。熱損失 Q は一様と仮定する。

ケース2: 別の固定温度条件（ディリクレ条件）

左右の2辺を高温 TH、上下の2辺を低温 TL に固定する。熱は左右から内側へ伝わると予想される。Q は一様と仮定する。

ケース3: 対流による熱損失（ノイマン条件）

4辺すべてで対流熱損失を考える。周囲の空気温度は TH と仮定する。

表面熱流束（フーリエの法則）と対流による熱損失（ニュートンの冷却則 Q = h * (T_surface - T_air)）がつり合う条件を境界条件として用いる。この場合、境界上の値も未知数として解く必要がある。勾配で与えられる境界条件をノイマン条件という。

2次元領域の離散化

FVM を適用する最初の段階として、2次元領域をグリッドに分割し、制御体積とノードを定義する。

x 方向に n 分割、y 方向にも n 分割する。

各要素の位置は (i, j) で表し、i を x 方向、j を y 方向の添字とする。

温度 T はノード中心で定義され、Tij と書く。

x 方向の制御体積の長さ Δxi、y 方向の長さ Δyj を定義する。

このグリッドを用いて支配方程式の離散化を進めていく。

05-01 講義: 2次元熱伝導と有限体積法

日時: 2026-05-01 10:00:13

場所: [場所を挿入]

講師: [氏名を挿入]

概要

この講義では、有限体積法（FVM）を用いて2次元定常熱伝導方程式の離散化方程式を、段階を追って明確に導出した。講師は、支配方程式に体積積分を適用し、ガウスの定理によって微分の次数を下げ、隣接ノード（東、西、北、南）に対する係数を定義する方法を説明した。その考え方は1次元や3次元にも一般化できることが示された。最後に、Jacobi 法と Gauss-Seidel 法（緩和、すなわち SOR を含む）といった反復解法を紹介し、導出した式を Python で実装する演習へつなげた。さらに、Codex のような AI ツールでも類似のコードを生成できることを示しつつ、理論を理解していることの重要性を強調した。

知識点

1. FVM による2次元離散化方程式の導出

支配方程式と制御体積の設定

x 方向と y 方向の偏微分を含む一般的な2次元支配方程式から出発する。

支配方程式を制御体積上で積分することで FVM を適用する。

制御体積はノード (i, j) を中心に持ち、大きさは Δxᵢ と Δyⱼ である。

隣接ノードを、西 (i-1, j)、東 (i+1, j)、北 (i, j+1)、南 (i, j-1) と定義する。

制御体積の各面を、西 (W)、東 (E)、北 (N)、南 (S) と名付ける。

ガウスの定理の適用と各項の離散化

ガウスの定理を用いて、2階微分を制御体積面での1階の流束表現へ変換する。

x 方向の項: x に関する2階微分の積分は、東面と西面での勾配差にセル高さ Δyⱼ を掛けた形になる。

東面の勾配 ≈ (Tᵢ₊₁,ⱼ - Tᵢ,ⱼ) / (0.5Δxᵢ₊₁ + 0.5Δxᵢ)

西面の勾配 ≈ (Tᵢ,ⱼ - Tᵢ₋₁,ⱼ) / (0.5Δxᵢ + 0.5Δxᵢ₋₁)

y 方向の項: 同様に、y に関する積分は北面と南面の勾配差にセル幅 Δxᵢ を掛けた形になる。

北面の勾配 ≈ (Tᵢ,ⱼ₊₁ - Tᵢ,ⱼ) / (0.5Δyⱼ₊₁ + 0.5Δyⱼ)

南面の勾配 ≈ (Tᵢ,ⱼ - Tᵢ,ⱼ₋₁) / (0.5Δyⱼ + 0.5Δyⱼ₋₁)

熱源項: 一定熱源 q を体積で積分すると qΔxᵢΔyⱼ となる。

最終的な代数方程式の構成

離散化した各項をまとめて1本の代数方程式にする。構造をそろえるため、西項と南項は順序を反転して符号を正にそろえる。

隣接係数として Cₑ（東）、Cw（西）、Cₙ（北）、Cs（南）を定義する。

Cₑ = Δyⱼ / (0.5Δxᵢ + 0.5Δxᵢ₊₁)

Cw = Δyⱼ / (0.5Δxᵢ₋₁ + 0.5Δxᵢ)

Cₙ = Δxᵢ / (0.5Δyⱼ₊₁ + 0.5Δyⱼ)

Cs = Δxᵢ / (0.5Δyⱼ + 0.5Δyⱼ₋₁)

簡略化した式は次のようになる:

Cₑ(Tᵢ₊₁,ⱼ - Tᵢ,ⱼ) + Cw(Tᵢ₋₁,ⱼ - Tᵢ,ⱼ) + Cₙ(Tᵢ,ⱼ₊₁ - Tᵢ,ⱼ) + Cs(Tᵢ,ⱼ₋₁ - Tᵢ,ⱼ) = -qΔxᵢΔyⱼ/λ

中心係数は C₀ = Cₑ + Cw + Cₙ + Cs。

これを Tᵢ,ⱼ について解くと、

Tᵢ,ⱼ = (1/C₀)[CₑTᵢ₊₁,ⱼ + CwTᵢ₋₁,ⱼ + CₙTᵢ,ⱼ₊₁ + CsTᵢ,ⱼ₋₁] - (qΔxᵢΔyⱼ)/(λC₀)

となる。

この式は、Tᵢ,ⱼ が周囲の温度の重み付き平均として表され、その重みを各係数が与えていることを示している。

2. 一般化と反復解法

1次元、2次元、3次元への一般化

この導出手順は次元をまたいで体系的に拡張できる。

1次元の場合: Tᵢ は東側 (i+1) と西側 (i-1) のみで決まる。

Tᵢ = (1/C₀)[CₑTᵢ₊₁ + CwTᵢ₋₁]

2次元の場合: 導出した通り、東、西、北 (j+1)、南 (j-1) を用いる。

3次元の場合: さらに右 (R, k+1) と左 (L, k-1) が加わる。C₀ は6方向の和、すなわち Cₑ + Cw + Cₙ + Cs + Cᵣ + Cₗ になる。係数の定義も同様に拡張され、例えば Cᵣ の分子には ΔxᵢΔyⱼ が現れる。

反復解法

Jacobi 法: 右辺に現れる未知数には、すべて前反復の予測値（上付き P）を用いる。単純だが収束が遅いことがある。

Gauss-Seidel 法: その反復内で得られた最新値を使うことで Jacobi 法を改良する。i、j のループで計算する場合、西側 (i-1) と南側 (j-1) は更新済み値を使い、北側 (j+1) と東側 (i+1) は予測値を使う。

逐次過緩和法（SOR）: Gauss-Seidel 法と組み合わせて収束を速めたり安定化したりするためによく使われる。まず一時値 Tᵢ,ⱼ* を計算し、それと前の値の重み付き平均で新しい Tᵢ,ⱼ を更新する。重みは緩和係数 β（0〜1）で与える。
