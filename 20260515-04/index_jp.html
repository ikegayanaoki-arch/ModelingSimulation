概要

この講義では、まず有限体積法 (FVM) を用いた二次元定常熱伝導方程式の復習を行い、その後、一次元非定常熱伝導方程式の数値シミュレーションを詳しく導入する。主な焦点は、一次元金属棒における温度分布の時間発展を追跡することである。講義では、非定常問題を解くための二つの基本的な数値手法、すなわち陽解法と陰解法を導入し、それらを比較する。新たな蓄積項を含む支配方程式の離散化を説明し、空間差分項をどの時間ステップで評価するかによって陽解法または陰解法になることを示す。最後に、理解を深めるために、両手法のフローチャートを作成する課題が与えられる。

講義要約

知識ポイント 1. 二次元定常熱伝導の復習 支配方程式 講義では、以前に解いた二次元定常熱伝導方程式、すなわち ∂²t/∂x² + ∂²t/∂y² = S を再確認する。ここで t は温度、 S はソース項である。スライドには誤植があり、 t ではなく ∂²t であるべきだと指摘された。 有限体積法 (FVM) による離散化 格子を定義し、各点を添字 (i, j) で表す。対応する温度は T(i,j) である。 支配方程式をコントロールボリューム上で積分する。 ガウスの定理を用いて、二階偏微分をコントロールボリューム各面 (東、西、北、南) で評価される一階微分へと変換する。 最終的な離散化方程式では、ノード T(i,j) の温度が、その周囲のノード (T(i+1,j), T(i-1,j), T(i,j+1), T(i,j-1)) とソース項の関数として表される。CO, CE, CW, CN, CS は各ノードの寄与を表す係数である。 これまでのケーススタディ 以前にシミュレーションした三つの条件の簡単な復習: ケース1: 上側のみを加熱し、残り三辺は低温とする。 ケース2: 左右の二辺を加熱し、上下面は低温とする。 ケース3: 周囲空気温度を一定とし、境界温度を計算する熱対流条件。 これらのケースの温度分布結果が示され、高温領域から低温領域への熱移動が確認された。 2. 一次元非定常熱伝導シミュレーション 問題設定 講義は定常問題から非定常、すなわち時間依存問題へと焦点を移す。 シミュレーションは一次元に単純化される。 目的は、温度 T が位置 x と時間 t の両方に対してどのように変化するかを追跡することである。温度は T(x, t) の関数である。 支配方程式 一次元非定常熱伝導方程式には、時間による温度変化を表す蓄積項が含まれる。 方程式は ρ * Cp * (∂T/∂t) = λ * (∂²T/∂x²) である。 ρ * Cp * (∂T/∂t) は蓄積項である。 λ * (∂²T/∂x²) は拡散項である。 ρ (rho) は密度、Cp は比熱、λ (lambda) は熱伝導率である。 境界条件と初期条件 境界条件 (BC): 一次元棒の両端の温度は固定される。一端は低温 TL ( T(x=0, t) = TL )、もう一端は高温 TH ( T(x=L, t) = TH ) である。 初期条件 (IC): 初期温度分布を与える必要がある。この問題では、t=0 における初期温度は全 x に対して一様に低温 TL とされる (T(x, t=0) = TL)。 期待される温度発展 シミュレーションでは、平坦な初期条件 ( t=0 ) から、線形な定常解 ( t → ∞ ) へと温度分布が発展していく様子を追跡する。 中間時刻では、固定された境界条件を満たしながら温度分布が徐々に変化する。 3. 一次元非定常方程式の離散化 格子とノードの定義 一次元棒は N 個のコントロールボリュームに分割される。 ノードは各コントロールボリュームの中心に定義され、添字 i で表される。ノード i の温度は Ti である。 新たな離散化パラメータとして時間刻み Δt が導入される。 支配方程式の積分 FVM を用いて、支配方程式をコントロールボリューム Δx 上で積分する。 拡散項 (右辺): 定常状態と同じ離散化であり、隣接ノードとの温度差 (Ti+1, Ti, Ti-1) を含む形になる。 蓄積項 (左辺): 時間微分 ∂T/∂t は一次の前進差分 (T(n+1) - T(n)) / Δt で離散化される。ここで n は時間ステップ添字である。 コントロールボリューム Δxi で積分すると、離散化された蓄積項は ρ * Cp * ( (Ti(n+1) - Ti(n)) / Δt ) * Δxi となる。 一般的な離散化方程式 各項を組み合わせると、一般式 CO * (Ti(n+1) - Ti(n)) = CE * (T(i+1) - Ti) + CW * (T(i-1) - Ti) が得られる。 係数は次のように定義される: CO = ρ * Cp / Δt (注: 転記元の講義記録では、積分体積に対応する Δxi が式から抜けているように見える)。 CE = λ / (0.5 * (Δx(i+1) + Δxi)). CW = λ / (0.5 * (Δxi + Δx(i-1))). 4. 陽解法と陰解法 中心概念 本質的な違いは、空間差分項 (拡散項) をどの時間ステップ ( n または n+1 ) で評価するかにある。 陽解法 定義: 空間勾配を前の時間ステップ n で評価する。 式: 次の時間ステップの温度 Ti(n+1) は、前の時間ステップ n の既知値だけを用いて明示的に計算される。 Ti(n+1) = (1/CO) * [ CE*Ti+1(n) + CW*Ti-1(n) + (CO - CE - CW)*Ti(n) ] 特徴: 各時間ステップごとの計算は直接的であり、計算効率がよい。 反復ソルバを必要としない。次の状態は前の状態から一回の計算で決まる。 図で見ると、(i, n+1) の値は (i-1, n), (i, n), (i+1, n) の値に依存する。 陰解法 定義: 空間勾配を現在の未知な時間ステップ n+1 で評価する。 式: Ti(n+1) の式には、同じ n+1 時刻における隣接ノードの未知温度 Ti+1(n+1), Ti-1(n+1) が含まれる。 Ti(n+1) = (1/CD) * [ CE*Ti+1(n+1) + CW*Ti-1(n+1) + CO*Ti(n) ] , ここで CD = CO + CE + CW である。 特徴: これは時刻 n+1 における全ノードの連立一次方程式系を形成する。 Ti(n+1) が同じ時刻の未知量 Ti+1(n+1), Ti-1(n+1) に依存するため、温度を求めるには反復法 (定常問題で用いたガウス・ザイデル法のような手法) が必要である。 図で見ると、(i, n+1) の値は (i, n) と、未知の (i-1, n+1), (i+1, n+1) に依存する。 連絡事項 2026年5月22日の講義は休講である。 2026年5月29日に、内容理解を確認するためのミニクイズを実施する。 このクイズは成績評価のためではなく、理解確認および講義の有効性確認のためである。 質問 [質問・疑問点を記入] 課題 1. 時間発展の計算ループを示した陽解法のフローチャートを描く。 2. 各時間ステップでの収束反復ループを含む陰解法のフローチャートを描く。 3. 次の時間ステップ温度がどのように決まるかを含め、陽解法と陰解法の違いを理解する。 4. 2026年5月29日のミニクイズに備えて講義内容を復習する。

概要

この講義では、一次元非定常熱伝導問題を解くための陽解法と陰解法の違いを説明する。教員はフローチャートを使って手続き上の違いを示し、陽解法が単純な一重ループであるのに対し、陰解法では各時間ステップで収束を確かめるための内側の反復ループが必要になることを強調する。中心的なテーマは、収束条件を通じた数値安定性の理論解析である。講義では拡散数 (R) を導出し、陽解法が R < 0.5 を必要とする「条件付き安定」であり、時間刻み Δt が空間刻み Δx に強く制約されることを示す。一方、陰解法は時間刻みの大きさに関係なく収束する「無条件安定」である。また、数値安定性が精度を保証するわけではないことも説明し、最後に Python による両手法の実装演習で締めくくられる。

講義要約

知識ポイント 1. 陽解法と陰解法の比較 基本的な手続き上の違い 陽解法では、次の時間ステップ (n+1) の温度を、現在の時間ステップ (n) の温度から直接計算する。各時間ステップで収束のための反復は不要である。 陰解法では、次の時間ステップ (n+1) の温度を、その同じ未来時刻 (n+1) の温度に基づいて計算するため、先へ進む前に各時間ステップで反復して収束させる必要がある。 フローチャートとループ構造 陽解法: 項を計算し、値を次の時間ステップへ更新し、定常状態または所定の終了時刻に達するまでこの時間ループを繰り返す、単純な一重ループ構造である。 陰解法: 外側の時間ループと、各時間ステップで温度を収束するまで繰り返し更新する内側の反復ループからなる二重ループ構造を持つ。 2. 数値安定性と収束条件 収束条件の概念 数値手法が安定で収束する解を与えるか、あるいは発散するかを決める。 解析では、繰り返しの時間更新によって生じる等比級数の中で、前の時間ステップ温度 (Tᵢⁿ) に掛かる係数に着目する。 陽解法: 条件付き安定 導出: 次の時間ステップ温度 (Tᵢⁿ⁺¹) は (1 - 2R) * Tᵢⁿ に比例する。ここで R は拡散数である。 拡散数 (R): 重要な無次元パラメータで、R = A * Δt / (Δx)^2 と表される。A は熱拡散率 (λ / (ρ * c_p))、Δt は時間刻み、Δx は格子幅である。 安定条件: 収束のためには (1 - 2R) が -1 と 1 の間になければならず、0 < R < 0.5 が得られる。 実用上の意味: 時間刻みの制約は Δt < (Δx)^2 / (2A) である。Δx を半分にすると、Δt は 4 分の 1 以下にしなければならず、計算時間が増加する。 名称: 安定性が Δt と Δx の選び方に依存するため、「条件付き安定」と呼ばれる。 陰解法: 無条件安定 導出: 次の時間ステップ温度 (Tᵢⁿ⁺¹) は (1 / (1 + 2R)) * Tᵢⁿ に比例する。 安定条件: A, Δt, Δx が正であるため、1 / (1 + 2R) は任意の正の R に対して常に 0 と 1 の間にある。 実用上の意味: 任意の Δt、Δx に対して数値的に安定である。 名称: 「無条件安定」。この頑健性のため、深い数値解析知識がない利用者でも安定な解を得やすく、多くの商用シミュレーションソフトで採用されている。 安定性と精度 数値安定性と精度は別概念である。 無条件安定な陰解法でも発散は避けられるが、必ずしも正確とは限らない。 両手法とも、離散化誤差を小さくして連続体の真の解に近づけるには、十分に小さい Δt と Δx が必要である。陰解法であっても高精度のためには細かい Δt が必要である。 質問 [質問・疑問点を記入] 課題 1.
